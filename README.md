# Zingen

![Captura de tela da landing page Zingen](./screenshots/zingen.png)

Landing page de um aplicativo fictício de karaokê, criada com foco no estudo de responsividade.

## Sobre o projeto

A página apresenta as funcionalidades do app, opções de assinatura e links para download. O layout se adapta a diferentes tamanhos de tela usando HTML e CSS.

## Como visualizar

Abra o `index.html` no navegador ou inicie um servidor local na pasta do projeto:

```bash
python3 -m http.server 8000
```

Depois, acesse http://localhost:8000.
